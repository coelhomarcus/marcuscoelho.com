Bem-vindo ao meu ambiente de desenvolvimento! O conteúdo estará em constante mudança, já que gosto de experimentar sempre coisas novas.

O tema que costumo utilizar no VS Code é o [BakaNeo](https://marketplace.visualstudio.com/items?itemName=coelhomarcus.bakaneo), que eu mesmo fiz, mas também uso Min Theme, Vesper++ e Github Theme.

### Ferramentas

`VS Code` - Code editor, não preciso falar mt desse :P

`Yaak` - API Client - testar, depurar e organizar requisições.

`DBeaver` - Programa completo para gerenciamento e visualização de bancos de dados.

`DBunny` - Programa de gerenciamento de banco de dados ProstgreSQL focado em simplicidade (feito por mim).

`Tinycast` - Spotlight so que bom! (antes utilizava o Raycast).

`Ghostty` - Terminal moderno, focado em desempenho e com aceleração por GPU.

`Mole` - Ferramenta que faz uma limpeza geral no seu Mac.


### Deploy e Serviços

`VPS` - Hostinger KVM2.

`Dokploy` - lataforma de gerenciamento e deployment de aplicações.

`Resend` - Serviço de envio de e-mails transacionais.
