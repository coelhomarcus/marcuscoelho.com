Bem-vindo ao meu ambiente de desenvolvimento! O conteúdo está em constante mudança, já que gosto de sempre experimentar coisas novas.

_Última atualização: 19.09.2026_

## Editor

Uso o [VS Code](https://code.visualstudio.com) como editor, não preciso falar muito dele :P

O tema que mais uso é o [BakaNeo](https://marketplace.visualstudio.com/items?itemName=coelhomarcus.bakaneo), que eu mesmo fiz. De vez em quando também alterno entre:

- Min Theme
- Vesper++
- GitHub Theme

### settings.json

As poucas configurações que mudo do padrão:

```json
{
    "workbench.secondarySideBar.defaultVisibility": "hidden",
    "workbench.browser.openLocalhostLinks": false,
    "explorer.compactFolders": false,
    "explorer.confirmDelete": false,
    "editor.wordWrap": "on",
    "editor.minimap.enabled": false,
    "js/ts.updateImportsOnFileMove.enabled": "always"
}
```

## Ferramentas

- **[Ghostty](https://ghostty.org)**: terminal moderno, focado em desempenho e com aceleração por GPU.
- **[Yaak](https://yaak.app)**: cliente de API para testar, depurar e organizar requisições.
- **[DBeaver](https://dbeaver.io)**: programa completo para gerenciar e visualizar bancos de dados.
- **[DBunny](https://github.com/coelhomarcus/dbunny)**: gerenciador de bancos PostgreSQL focado em simplicidade, feito por mim.
- **Tinycast**: um Spotlight, só que bom! Antes eu usava o Raycast.
- **Mole**: faz uma limpeza geral no Mac.

## Deploy e serviços

- **VPS**: KVM 2 da [Hostinger](https://www.hostinger.com).
- **[Dokploy](https://dokploy.com)**: plataforma para gerenciar e fazer deploy das aplicações.
- **[Resend](https://resend.com)**: envio de e-mails transacionais.
